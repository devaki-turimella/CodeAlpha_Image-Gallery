# 🎬 Image Gallery

### 🎯 What I Was Asked to Do

Create a creative and interactive image gallery using **HTML, CSS, and JavaScript**.

### 💡 What I Did

I turned the basic gallery idea into a **movie-themed visual experience** based on my interest in movies and characters. I organized it into **Heroes, Villains, Movies, and Videos**, with a simple and engaging design.

### ✨ My Creativity

Instead of making a normal photo gallery, I gave it a **cinematic touch** with interactive elements, visuals, and multimedia to make exploring the gallery more fun.

**Built with:** HTML • CSS • JavaScript
